项目简介

用最朴素的技术，把一套完整战斗闭环讲清楚。

做一款随手可玩、无需安装与构建的 2D 竞技原型并不难，难的是用极少的代码把"输入 → 武器状态机 → 命中检测 → 同帧仲裁 → 物理结算 → 胜负判定"的链路讲透。本项目用 ES5 风格 JS + Canvas 做到了，核心设计是两方武器机制不对称：红方负责"拉"，蓝方负责"推"，再叠加一套"重克轻、重撞重双弹"的仲裁规则，制造出可观的策略深度。它是学习战斗系统架构的极佳样本。

核心玩法

红蓝两方武器机制相反，却在同一套物理与仲裁框架下对抗。

RED · HOOK

钩锁（拉拽型）

  • 发射钩索，命中后沿出钩反方向把目标拉向自己
  • 命中即造成短僵直，打断对方节奏
  • 轻勾随手即发；重勾需蓄力
  • 钩尖碰到墙/障碍会自动收回
★ 重勾：拉力与眩晕更强，蓄力期间有闪光提示
BLUE · FORK

钢叉（击退型）

  • 瞬间突刺，命中后沿出叉方向把目标击退
  • 命中造成僵直，配合场地把人推下深渊
  • 轻叉随手即发；重叉需蓄力
  • 命中检测用"线段 vs 圆"算法，贴合长兵器
★ 重叉：击退力更大，目标撞墙/障碍则钉墙 1 秒
🎯 胜利条件：歼灭敌方全员，或 180 秒时限内存活人数多者胜；人数相同判平局。踏入深渊格（纯黑危险区）即死。

命中仲裁规则

武器只"上报"命中，由 HitResolver 统一裁决同帧冲突——不依赖代码执行顺序，结果确定。

情形结果
同阵营命中始终生效（不受仲裁影响）
轻 vs 轻双方均生效
重 vs 轻重生效，轻被弹开
重 vs 重双方弹开，攻击者各僵直 1 秒
多人重攻击命中同一目标全部弹开，目标也僵直 1 秒

设计亮点

六个值得借鉴的工程取舍。

01

数据驱动调参

所有平衡数值集中在 config.js，改数值即改手感，逻辑零改动。

02

命中仲裁解耦

武器只"上报"不"结算"，由 Resolver 统一裁决，逻辑清晰且利于联机化。

03

网格化场地

障碍/深渊用 "c,r" 集合存储，查询 O(1)；随机生成带间距与出生点保护。

04

武器状态机

Hook/Fork 生命周期完备（蓄力→伸出→收回→冷却），细节特效齐全。

05

网络同步预留

Player/Weapon/Level 均实现 serialize/fromData，已留好联机接口。

06

零依赖零构建

纯前端双击即玩，是教学与原型验证的低成本样本。

快速开始

三种启动方式，无需 npm install。

① 直接用浏览器打开 index.html；② 推荐本地起静态服务器避免文件限制：

cd HOOK_AND_FORK
python -m http.server 8000
# 浏览器访问 http://localhost:8000

③ 大厅按 空格 → 看说明再按 空格 → 倒计时开战。

红方 WASD + 鼠标（左键轻勾 / 右键重勾）；蓝方 方向键 + , 轻叉 / . 重叉。
